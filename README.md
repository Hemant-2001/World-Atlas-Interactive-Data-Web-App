## ✨ **Overview**

**World Atlas** is a fully responsive React.js application that displays information about all countries using the **REST Countries API**.

Users can:

* Search any country
* Filter by region
* View complete details
* Open map location
* Explore rich data in an elegant UI

Made with clean code, smooth UI, and optimized performance.

---

# 🔥 Features

### 🔍 **Search & Region Filter**

* Real-time search
* Filter by Asia / Europe / Africa / Americas / Oceania

### 🌐 **Country Details Page**

* Flag
* Population
* Capital
* Languages
* Borders
* Google Maps link

* Tailwind responsive layout

# 🧩 Tech Stack

| Technology             | Usage          |
| ---------------------- | -------------- |
| **React.js**           | Frontend logic |
| **React Router**       | Navigation     |
| **Tailwind CSS**       | Styling        |
| **Axios**              | API Requests   |
| **REST Countries API** | Country Data   |

> API Used: [https://restcountries.com/v3.1/all](https://restcountries.com/v3.1/all)

# ⚙️ Installation

### 1️⃣ Clone Repo

```bash
git clone https://github.com/USERNAME/World-Atlas.git
cd World-Atlas
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Run Project

```bash
npm run dev
```
